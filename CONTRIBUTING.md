# Contributing

This repository is archived and does not accept changes to the retired Letta V1 server.

For current Letta development, bug reports, and feature requests, use [`letta-ai/letta-code`](https://github.com/letta-ai/letta-code). The historical V1 server source remains available on this repository's [`archive`](https://github.com/letta-ai/letta/tree/archive) branch for reference only.
